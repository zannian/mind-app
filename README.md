# 惦 Mind

两个人的关怀提醒工具。Android（Kotlin + Compose）+ Node.js（Fastify）+ SQLite。

## 目录

| 路径 | 说明 |
|---|---|
| `docs/` | 产品定义与落地文档（需求源） |
| `prototype/` | 可交互原型 / 视觉规范（浏览器打开 `mind-prototype.html`，加 `#board` 看总览） |
| `design/` | 品牌与设计源文件（Logo 等），暂空 |
| `android/` | Android 客户端 |
| `backend/` | 自建后端 |
| `AGENTS.md` | 给 Agent 的硬约束与已拍板决策 |

权威顺序见 `AGENTS.md`：文档管状态与文案，原型管视觉；账号/配对/称呼以 `AGENTS.md` 为准。

## 快速开始

见 `backend/README.md` 与 `android/README.md`。
